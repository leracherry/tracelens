# TraceLens v1.0.0

TraceLens 1.0 is the production-readiness release: stable public APIs, a polished local debugging workflow, strict telemetry validation, hardened Studio boundaries, complete reference documentation, runnable examples, and verified distribution artifacts.

## What is stable

- Browser initialization, shutdown, marks, custom spans, privacy controls, batching, and retry behavior.
- Interaction, INP, long-frame, layout-shift, fetch/XHR, and Web Vital capture where browser APIs permit it.
- React Profiler boundaries with commit duration and render-count attribution.
- Release metadata, ReleaseScope comparisons, CLI inspection, source maps, and GitHub source links.
- OTLP/HTTP JSON export and opt-in, origin-allowlisted trace-context propagation.
- Release and route performance budgets plus GitHub Checks, summaries, artifacts, and pull-request comments.
- The version 1 telemetry protocol and storage adapter contracts.

## Final-phase hardening

- Validate every supported event type and payload at collector and file-ingestion boundaries; reject unknown event types, invalid timings, malformed trace contexts, and negative durations.
- Restrict browser access to the local Studio collector to loopback origins instead of exposing permissive cross-origin reads and writes.
- Fix `sampleRate: 0` so even a zero-valued random sample can never initialize telemetry.
- Read the CLI version from its package manifest, removing a manual version-drift point.
- Point package runtime and type exports at shipped build artifacts, with tarball smoke tests that verify imports, declarations, the CLI, and bundled Studio.
- Fail release publication before creating downstream packages or releases when npm publication fails.
- Add local documentation-link validation to CI and release workflows.

## Product polish

- Adopt one restrained, accessible interface system across Studio, ReleaseScope, Playground, and the documentation site.
- Refresh all static screenshots, the animated Studio tour, and the visual-regression baseline.
- Rebuild the repository README around real workflows, architecture, packages, privacy boundaries, and quality guarantees.
- Add task-oriented workflow and troubleshooting guides, browser/CLI/configuration reference pages, and Vite integration documentation.
- Add complete Vanilla TypeScript and React + Vite examples alongside existing budget, Action, OTLP, and trace fixtures.

## Upgrade

Keep all TraceLens packages on the same version:

```bash
npm install \
  @leracherry/tracelens-browser@1.0.0 \
  @leracherry/tracelens-react@1.0.0

npx @leracherry/tracelens-cli@1.0.0 studio
```

The telemetry protocol remains version 1, so valid v0.x trace files remain compatible. The stricter runtime guard can reject malformed or unofficial event payloads that earlier versions accepted shallowly.

## Operational boundaries

Studio remains a loopback-only, unauthenticated development tool with bounded in-memory storage. Browser Performance API coverage varies, production React profiling requires a profiling-enabled build, and release comparisons describe captured samples rather than statistical significance.
