# TraceLens v0.2.1

Fixes package publication by using the account-owned `@leracherry/tracelens-*` namespace on both npm and GitHub Packages.

- All nine packages, workspace imports, examples, and documentation now use the same namespace.
- CI tests installation of the actual release tarballs, runtime imports, CLI version, and bundled Studio.
- Both registries receive matching package names and dependency versions; no registry-specific import rewriting is needed.
- Privacy controls and OpenTelemetry support from v0.2.0 are unchanged.

## Install from npm

```bash
npm install @leracherry/tracelens-browser@0.2.1
npx @leracherry/tracelens-cli@0.2.1 studio
```

```ts
import { init } from '@leracherry/tracelens-browser';
init({ app: 'dashboard', endpoint: 'http://127.0.0.1:4173/__tracelens' });
```

Replace old `@tracelens/browser` imports with `@leracherry/tracelens-browser` (and likewise for every package). Keep all packages on 0.2.1. GitHub Packages users already using the account scope only need to update versions.

See [registry setup](https://github.com/leracherry/tracelens/blob/main/docs/guides/publishing.md). GitHub Release assets contain all nine npm tarballs.
