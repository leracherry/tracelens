# tracelens v1.1.1

This patch refines Studio and Playground and updates the docs to show the current UI.

- Toggle between Light and Dark with a single sun or moon button. Studio remembers your choice, and the wordmark uses white lettering in dark mode.
- Use keyboard-accessible dropdowns for Studio filters and release comparisons, and for Playground settings. The active Studio tab identifies the current view.
- The refreshed icon, wordmark, and blue accents appear across the apps and docs. The README features light-mode screenshots and a lossless animated tour.

The telemetry protocol remains at version 1.

```bash
npx @leracherry/tracelens-cli@1.1.1 studio
```

See the [Studio workflows guide](../guides/workflows.md) for the updated walkthroughs.
