# TraceLens v0.3.0

Source-level long-frame attribution and a more visual repository presentation.

## Highlights

- Import external `.js.map` and `.mjs.map` files into a bounded local source-map store with `tracelens sourcemaps upload`.
- Record Long Animation Frame `sourceCharPosition` offsets and resolve them against the exact generated script for the matching app and release.
- Show original file, line, column, mapped function name, and safe commit-pinned GitHub links in Studio.
- Preserve unresolved contributions instead of guessing locations when maps or positions are unavailable.
- Add authentic Studio interaction and ReleaseScope screenshots plus a reproducible Playwright capture script.
- Refresh README navigation, product story, architecture overview, badges, package documentation, and repository metadata.

## Source-map quick start

```bash
npx @leracherry/tracelens-cli@0.3.0 sourcemaps upload ./dist \
  --app dashboard \
  --release 2.14.0 \
  --url-prefix https://app.example.com/ \
  --repository https://github.com/owner/repo \
  --commit 7ac841f

npx @leracherry/tracelens-cli@0.3.0 studio
```

The app and release must match browser telemetry, and the generated URL match is exact. Imports are local, immutable per app/release, and limited to 20 MiB. Source contents are removed from imported maps. TraceLens never fetches maps from telemetry URLs.

See the [source-map guide](https://github.com/leracherry/tracelens/blob/main/docs/guides/source-maps.md) for supported map formats, privacy behavior, and GitHub-link rules.

## Compatibility and limits

All packages should be upgraded together to 0.3.0. The public package namespace remains `@leracherry/tracelens-*`.

Source resolution supports flat v3 maps and Chromium's Long Animation Frames character offsets. It does not yet support indexed maps, inline maps, error-stack mapping, or remote uploads. Studio remains a local, unauthenticated, in-memory tool.
