# TraceLens v0.1.0

The first public release brings browser interaction debugging and release comparisons to a local Studio.

## Included

- Browser Event Timing, INP subparts, LCP, CLS, long animation frames, fetch/XHR timing, and custom spans.
- React Profiler boundaries with interaction correlation and component timing tables.
- A Vite plugin that injects release, commit, environment, and build timestamp.
- ReleaseScope comparisons for interaction and route timings, LCP, long frames per session, and React components.
- A standalone CLI with bundled Studio, `inspect`, `compare`, and `doctor` commands.
- Protocol, core, and memory/file storage packages with compiled ESM and TypeScript declarations.

## Quick start

```bash
npm install @tracelens/browser
npx @tracelens/cli@0.1.0 studio
```

See the [getting started guide](https://github.com/leracherry/tracelens/blob/main/docs/guides/getting-started.md) for SDK configuration.

## Limits in this release

Studio stores up to 50,000 events in memory and clears them when stopped. It is a local development tool and has no authentication. Keep its default loopback host.

Browser support varies by Performance API. React production profiling requires a profiling-enabled React build. Release comparisons are descriptive: the current INP p75 is computed across captured interaction durations, LCP p75 across captured LCP samples, and render counts are raw sample counts. Populations and capture lengths can differ; percentage changes do not establish statistical significance. The Studio highlights changes above 5%. Long-frame count increases do not identify individual new frame sources.

Privacy configuration, source-map resolution, OpenTelemetry export, CI budgets, and hosted collection are not included in v0.1.0. Review application-supplied names, labels, routes, and metadata before collecting production telemetry.

## Registries

The npm distribution uses `@tracelens/*`. GitHub Packages uses the repository owner's namespace, `@leracherry/tracelens-*`. Tarballs attached to this release are the npm distribution.
