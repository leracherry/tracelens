# tracelens v1.1.0

tracelens 1.1 improves the workflow from finding a slow interaction to inspecting its source-linked evidence and checking which release introduced the regression.

## Studio and Playground

- Search captures by interaction name or route and combine the search with release and route filters. Studio keeps evidence visible through a temporary collector outage and preserves selection during live refresh.
- Inspect the shared timeline with a keyboard or pointer. Each event shows timing and the available source, React, or request details.
- Choose a baseline and candidate release, then use **View captures** to open matching candidate interactions. Return to the same comparison page and row.
- Use a redesigned light or dark workspace with aligned selects, readable status colors, and a dedicated mobile inspector.
- Explore all five Playground scenarios. Settings and checkout report demo API errors and allow a retry. The search scenario shows an explicit empty result.

## Verification and compatibility

The telemetry protocol remains version 1. The release checks cover the packaged CLI, the Studio and Playground workflows, and 12 visual baselines across both themes. Trace comparisons still describe the captured sample.

```bash
npx @leracherry/tracelens-cli@1.1.0 studio
```
