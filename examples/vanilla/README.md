# Vanilla TypeScript

This deliberately slow report calculation demonstrates automatic interaction timing, stable control names, marks, and explicit spans.

```bash
npx @leracherry/tracelens-cli@1.0.0 studio
npm install
npm run dev
```

Open the loopback URL printed by Vite, click **Calculate report**, then inspect the newest interaction in Studio.

The busy loop is intentional and belongs only in this example.
